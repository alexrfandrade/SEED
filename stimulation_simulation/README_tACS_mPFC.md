# tACS mPFC Optimization (SimNIBS Leadfield Approach)

## Overview

This script determines the optimal electrode montage (position and current) for **transcranial Alternating Current Stimulation (tACS)** targeting the medial prefrontal cortex (mPFC), using a leadfield-based optimization approach in **SimNIBS**.

The pipeline:

1. Computes the leadfield matrix for the subject's head model, using a 10-10 EEG electrode cap layout.
2. Converts the stimulation target from MNI coordinates to the subject's individual head space.
3. Optimizes the electrode montage to maximize the electric field at the target while constraining the total current, individual electrode current, and the number of active electrodes (2: one anode, one cathode).
4. Exports the results (current per electrode, electric field summary) and prints a formatted console report.

This script only performs the **electrode montage optimization** step. It assumes the subject's head model has already been segmented and meshed by SimNIBS beforehand (see Input below).

## Input

- A subject head model folder generated by SimNIBS's segmentation pipeline (`headreco` or `charm`), referenced here as `m2m_ernie`. **"ernie" is SimNIBS's official example/demo subject** — confirm whether you are using this demo subject (e.g. to test the pipeline) or your own segmented subject before interpreting the results. If using your own data, replace `SUBPATH` with your subject's `m2m_<subject_id>` folder.
- An EEG electrode cap position file (CSV), provided by default from SimNIBS's own resources (`EEG10-10_UI_Jurak_2007.csv`).

## Output

Saved under timestamped subfolders (`leadfield_mPFC/<timestamp>/` and `optimization_mPFC/<timestamp>/`) inside `WORK_DIR`:

| File | Description |
|---|---|
| `<subject_id>_leadfield_<cap_name>.hdf5` | Leadfield matrix computed for the subject and electrode cap. |
| `tACS_mPFC_2electrodes.csv` | Optimized current per electrode. |
| `tACS_mPFC_2electrodes_summary.txt` | SimNIBS's own text summary of the optimization (electric field at target, etc.). |

A console report is also printed, listing the active electrodes with their current (mA) and polarity (anode/cathode).

## Dependencies

- **MATLAB**
- **SimNIBS 4.x** (tested with 4.5), with `matlab_tools` available and added to the MATLAB path
- A segmented subject head model (`m2m_*` folder), produced separately by SimNIBS's `headreco`/`charm` pipeline — **not generated by this script**

## How to use

1. Make sure your subject's `m2m_*` folder is accessible, and that you know the path to your local SimNIBS installation.
2. Edit the configuration section at the top of the script:
   - `SIMNIBS_DIR`: path to your local SimNIBS installation
   - `WORK_DIR`: working directory containing (or that will contain) the subject's `m2m_*` folder; the script will `cd` into this folder
   - `SUBPATH`: name of the subject's `m2m_*` folder (default: `m2m_ernie`, the SimNIBS demo subject)
   - `EEG_FILE`: path to the EEG cap CSV file (default: SimNIBS's built-in 10-10 layout)
   - `MNI_TARGET`: target coordinates in MNI space (default: `[0, 52, -6]`, vmPFC — see references below)
   - Electrode geometry (`ELEC_RADIUS`, `ELEC_THICK`) and current constraints (`CURRENT_MA`, `MAX_INDIV_CURRENT`, `MAX_ACTIVE_ELECTRODES`, `TARGET_EFIELD`)
3. Run the script from MATLAB (`>> tACS_mPFC_optimization`), from a directory where `WORK_DIR` is reachable.
4. No manual/interactive step is required, but expect the leadfield calculation (step 1/3) to take approximately 20–60 minutes depending on your machine.

## Notes and known limitations

- `SIMNIBS_DIR` is added to the MATLAB path via `addpath`, but its existence is not checked beforehand; if the path is wrong, the resulting error ("SimNIBS MATLAB tools not found") may be less informative than it could be. Verify the path carefully if you hit this error.
- Current and target field parameters (`CURRENT_MA = 2 mA` total, `TARGET_EFIELD = 0.2` V/m) are hard-coded and not individually referenced in the script, unlike the MNI target coordinates (which are sourced from the literature — see below). 
- An alternative rectangular electrode geometry (commented out: `ELEC_LX`, `ELEC_LY`) and the Pardiso solver option (commented out) are present but inactive.
- This script processes a single subject/target per run.

## References and recommended parameters

- **mPFC target coordinates used**: MNI `[0, 52, -6]` (vmPFC / ventromedial prefrontal cortex), based on Fox et al. (2005, *PNAS*) and Reinhart & Nguyen (2019, *Nature Neuroscience*).
- Alternative targets: dmPFC at MNI `[0, 52, 26]`; sgACC at MNI `[0, 24, -12]`.
- Reported tACS parameters in the literature: 6 Hz (theta) or 40 Hz (gamma) depending on the cognitive goal; 1–2 mA peak-to-peak (0.5–1 mA per electrode); 20–30 min duration.
- **Mandatory citations if this pipeline contributes to a publication:**
  - Saturnino et al. (2019). *NeuroImage*, 203, 116183.
  - Saturnino et al. (2020). *bioRxiv*. doi:10.1101/2020.05.27.118422
